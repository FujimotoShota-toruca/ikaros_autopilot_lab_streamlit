# IKAROS-GO! (Darts-first / S-mode)

小学生でも遊べる「ダーツ」ゲームを目標にした、IKAROSっぽい体験ツールです。  
難しいB-planeの理屈は“裏側”にして、まずは

- **膜（帆）の向きを変えると、軌道が変わる！**
- **目標に近いほど高得点！**

を気持ちよく体験することを優先しています。

## 遊び方（5ターン）

1. **α（アルファ）**：太陽にどれくらい正面？（小さいほど強い）
2. **β（ベータ）**：どっち方向に押す？（角度）
3. 「実行！」で点が動きます（少しズレることもあります）
4. 5ターン後、目標に近いほど高得点

## 起動方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## いまは“ゲーム優先”

- 通信や発電の制約は **いったん無し**（あとで難易度調整として追加できます）
- 盤面の「金星の大きさ」は **スケール感の表示**として入れています
